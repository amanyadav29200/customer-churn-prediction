# Dataset

`Telco-Customer-Churn.csv` is IBM's public sample dataset for a fictional
telecommunications company. IBM documents `Churn` as whether a customer left
within the last month. The data is a static snapshot, so it is suitable for
learning binary churn classification and service association analysis. It does
not include a future cancellation date or per-product usage volumes.

- Source: [IBM's archived sample repository](https://github.com/IBM/telco-customer-churn-on-icp4d/tree/master/data)
- Direct CSV: [Telco-Customer-Churn.csv](https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv)
- Original rows and columns: 7,043 × 21
- SHA-256: `16320c9c1ec72448db59aa0a26a0b95401046bef5d02fd3aeb906448e3055e91`

The dataset is included for reproducibility. Check IBM's repository for its
license and source details before redistributing it outside this learning
project.
